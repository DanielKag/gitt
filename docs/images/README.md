# Screenshots

The README expects one image per screen, at these exact paths:

| File | Screen |
| --- | --- |
| `log.png` | `gitt log` |
| `status.png` | `gitt status` |
| `diff.png` | `gitt diff` |
| `branch.png` | `gitt branch` |

Until a file is added, GitHub renders its `![…]` line as a broken-image placeholder — that's the
reminder that the slot is still empty.

To capture one: run the command in a terminal sized around **100×30**, get the screen into the state
worth showing (a search typed, the diff pane open, the PR column filled in), and screenshot just the
terminal window. Keep the same terminal theme across all four so the set looks like one tool.
